# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute
1. Fork this repository and create a branch for your change.
2. Make and test your change.
3. Use a clear commit message.
4. Open a pull request describing what changed and why.
5. Be respectful and constructive when discussing feedback.

When reporting a bug, include steps to reproduce it, expected behavior, actual behavior, and relevant terminal output. Never include passwords, access tokens, or other secrets.
